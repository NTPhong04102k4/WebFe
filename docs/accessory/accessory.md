# Accessory API

Contract source: `docs/api/modules/accessory-category.md`.

Base path: `/accessories`

| Method | Path | Description |
|---|---|---|
| GET | `/accessories` | Paging and filtering accessories |
| GET | `/accessories/{id}` | Get accessory detail |
| POST | `/accessories` | Create accessory, multipart form |
| PUT | `/accessories/{id}` | Update accessory, multipart form |
