# Brand API

Contract source: `docs/api/modules/common-catalog.md`.

Base path: `/common`

| Method | Path | Description |
|---|---|---|
| GET | `/common/brands` | List car brands |
| POST | `/common/brands` | Create car brand |
| PUT | `/common/brands/{brandCode}` | Update car brand by natural key |
| GET | `/common/brand-accessories` | List accessory brands |
| POST | `/common/brand-accessories` | Create accessory brand |
| PUT | `/common/brand-accessories/{name}` | Update accessory brand by natural key |
