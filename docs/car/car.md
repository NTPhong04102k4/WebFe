# Car API

Contract source: `docs/api/modules/car.md`.

Base path: `/cars`

| Method | Path | Description |
|---|---|---|
| GET | `/cars` | Paging and filtering cars |
| GET | `/cars/{id}` | Get car detail |
| POST | `/cars` | Create car, multipart form |
| PUT | `/cars/{id}` | Update car, multipart form |
| GET | `/cars/{id}/tech-spec` | Get technical specification |
| POST | `/cars/{id}/tech-spec` | Create technical specification |
| PATCH | `/cars/{id}/tech-spec` | Update technical specification |
